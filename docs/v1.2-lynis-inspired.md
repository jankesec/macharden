# macharden v1.2 — Lynis-inspired macOS checks

Inspired by [Lynis](https://github.com/CISOfy/lynis) (GPLv3). **Do not copy Lynis source.** Reimplement ideas with native macOS commands, matching existing macharden style.

Version: `1.2.0`

## New checks

### Hardening (`lib/audit_hardening.sh`)

**HARD-12 Home Directory Permissions** (weight 6) — Lynis HOME-9304
- `_get_octal_perms` helper: copy the small function from `audit_secrets.sh` or inline `stat -f %OLp`
- PASS if `$HOME` is 700 or 750 (other bits 0). WARN if world-readable/writable (other class 4–7) or group-writable.
- Remediation: `chmod 700 "$HOME"`

**HARD-13 Network Time Synchronization** (weight 5) — Lynis TIME tests
- `systemsetup -getusingnetworktime 2>/dev/null`
- PASS if output contains `On`. WARN if `Off`. INFO if command fails.
- Remediation: `sudo systemsetup -setusingnetworktime on`

**HARD-14 Built-in Malware Protection** (weight 6) — Lynis MALW-3280 / XProtect analogue
- PASS if XProtect bundle exists: `/Library/Apple/System/Library/CoreServices/XProtect.bundle` OR `/System/Library/CoreServices/XProtect.bundle`
- Also note MRT: `/Library/Apple/System/Library/CoreServices/MRT.app` or `/System/Library/CoreServices/MRT.app` (optional in details)
- Optionally detect third-party AV as INFO (IsRunning-style): `pgrep -x` for `falcon-sensor`, `CylanceSvc`, `SentinelAgent`, `WdNisSvc` — do not FAIL if missing third-party AV; Apple XProtect is enough for PASS.
- WARN only if XProtect bundle is missing.
- No remediation that installs third-party AV.

### Network (`lib/audit_network.sh`)

**NET-10 IP Forwarding** (weight 7) — Lynis sysctl `net.inet.ip.forwarding`
- `sysctl -n net.inet.ip.forwarding` (and `net.inet6.ip6.forwarding` if present)
- PASS if both 0 / IPv6 missing. FAIL if IPv4 forwarding is 1 (host is a router). Related to Internet Sharing.
- Remediation: `sudo sysctl -w net.inet.ip.forwarding=0`

**NET-11 Promiscuous Interfaces** (weight 6) — Lynis NETW-3014
- `ifconfig -a 2>/dev/null` look for `PROMISC` in flags (not just the word in comments)
- WARN if any non-loopback interface is promiscuous. PASS otherwise.
- Remediation: review packet-capture tools; `sudo ifconfig <if> -promisc` if applicable.

### Secrets (`lib/audit_secrets.sh`)

**SEC-08 SSH Daemon Hardening** (weight 7) — Lynis SSH-7408, only when Remote Login is actually on
- If Remote Login is off (`systemsetup -getremotelogin` not On AND nothing listening on TCP 22) → PASS "sshd not exposed; daemon hardening skipped."
- Else collect config via `sshd -T 2>/dev/null` (preferred) or readable `/etc/ssh/sshd_config`.
- Flag WEAK if any of: `permitrootlogin yes`, `passwordauthentication yes` (WARN not FAIL — common on lab Macs), `x11forwarding yes`, `maxauthtries` > 6, `permitemptypasswords yes`.
- PASS if config readable and no weak options. WARN with list of weak options. INFO if sshd is listening but config unreadable.
- Remediation: comments pointing to `/etc/ssh/sshd_config` (PermitRootLogin no, MaxAuthTries 4, X11Forwarding no). Do not rewrite sshd_config automatically.

**SEC-09 Suspicious Shell History Files** (weight 5) — Lynis HOME-9310
- For `~/.zsh_history` `~/.zhistory` `~/.bash_history`: if exists and is NOT a regular file (symlink, directory, device) → WARN.
- PASS if missing or regular files.
- Remediation: "Investigate redirected history files (symlinks can hide attacker activity). Replace with a regular file."

### Persistence (`lib/audit_persistence.sh`)

**PERS-08 Printer Sharing** (weight 5) — Lynis printers/spoolers + CIS sharing
- `cupsctl 2>/dev/null` look for `_share_printers=1` or `SharePrinters Yes`
- Fallback: `launchctl list org.cups.cupsd` AND browsing enabled via `cupsctl`
- WARN if printer sharing on. PASS otherwise (CUPS not sharing, or cupsctl missing and no evidence).
- Remediation: `cupsctl --no-share-printers` or System Settings > General > Sharing > Printer Sharing off.

## Constraints

- Pure zsh, native macOS, no Lynis code copy.
- Aliases, run_audit_*, register_*_checks, header comments.
- Do not commit.
- Do not hang on GUI prompts.
- Bump MACHAR_VERSION in bin/macharden only from the docs agent; implementers of audit files do not touch bin/.
