# macharden v1.1 — Coverage & Reliability

Bump `MACHAR_VERSION` to `1.1.0`.

## New checks (native macOS only, zero extra deps)

Follow existing module style exactly: fallback `record_result`, ID aliases (`audit_hard_08` etc.), update `run_audit_*` and `register_*_checks`.

### Hardening (`lib/audit_hardening.sh`)

| ID | Title | Weight | Detect | Status |
|---|---|---|---|---|
| HARD-08 | Firmware Password / Recovery Lock | 8 | `firmwarepasswd -check` | Intel: PASS if "Password Enabled: Yes", FAIL if No. Apple Silicon / unsupported: INFO (firmware password N/A; Secure Boot covers this). Never hang on GUI. |
| HARD-09 | Secure Boot / Authenticated Root | 8 | `csrutil authenticated-root status`; `system_profiler SPiBridgeDataType` if present | PASS if authenticated-root enabled and (if reported) Secure Boot is Full Security. WARN if Reduced/Permissive or authenticated-root disabled. INFO if neither command yields data. |
| HARD-10 | Automatic Login Disabled | 6 | `defaults read /Library/Preferences/com.apple.loginwindow autoLoginUser` | FAIL if a username is set. PASS if key missing/empty. Remediation: `sudo defaults delete /Library/Preferences/com.apple.loginwindow autoLoginUser` |
| HARD-11 | Bluetooth Sharing | 5 | `defaults read /Library/Preferences/com.apple.Bluetooth PrefKeyServicesEnabled` (and `-currentHost` fallback) | WARN if `1`. PASS if `0` or unset. Remediation: `sudo defaults write /Library/Preferences/com.apple.Bluetooth PrefKeyServicesEnabled -bool false` |

Also tighten HARD-07 SSH detection: treat Remote Login as on only if `systemsetup -getremotelogin 2>/dev/null` matches On, or `sshd` is actually listening. Do not WARN solely because `launchctl list com.openssh.sshd` succeeds. Add Remote Apple Events via `systemsetup -getremoteappleevents` if available.

Gatekeeper remediation: prefer `sudo spctl --global-enable` with fallback comment for `--master-enable`.

### Network (`lib/audit_network.sh`)

| ID | Title | Weight | Detect | Status |
|---|---|---|---|---|
| NET-07 | AirDrop | 6 | `defaults read com.apple.NetworkBrowser DisableAirDrop`; `ifconfig awdl0` if present | PASS if DisableAirDrop==1 or awdl0 is down/absent. WARN if AirDrop radio is up / not disabled. Remediation: `defaults write com.apple.NetworkBrowser DisableAirDrop -bool true` |

Fix NET-01 fallback: numeric `1` or `2` from `defaults read … globalstate` must PASS.

## Engine / reliability (`bin/macharden`, `lib/engine.sh`, `lib/monitor.sh`, `lib/compliance.sh`, `lib/report_html.sh`)

1. Version `1.1.0`.
2. After reports/fix/alert, exit `1` if `COUNT_FAIL > 0`, else `0`. Daemon/help/version paths unchanged. Invalid flags still exit 1.
3. Validate `-c/--category` against `hardening|network|secrets|persistence|all`. Unknown → error to stderr, exit 1. Do **not** score 100% on empty unknown category.
4. `send_alert`: if `score_num < 70` and no FAIL branch matched, set subtitle/message about low hardening index (not empty body).
5. Remove hardcoded `BASE_DIR="<project_root>"` fallback in `compliance.sh`. If unresolved, warn and leave empty.
6. HTML compliance meters: load `compliance_map['mappings']` (not top-level). Use keys `cis` / `nist` / `mitre` (not `cis_benchmark`). If total is 0, percent is `0.0` not 85/82. Per-check chips should render CIS id / NIST primary / MITRE technique.

## Constraints

- Pure zsh, macOS native commands only. No new dependencies.
- Match existing comment/function style. No drive-by refactors.
- Do not commit. Do not edit files outside your assigned list.
- Checks must not hang on GUI password prompts (`security`, `ssh-keygen`). Redirect stdin from `/dev/null` where needed.
- Never print live secret values.
